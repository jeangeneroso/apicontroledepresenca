# 📊 Controle de Diárias e Reembolsos — Interface (Front-end)

Interface web desenvolvida em **Angular** para consumo da API do sistema de gestão de diárias.

> ⚠️ **Status do Projeto:** 🧪 *Em desenvolvimento / Fase de testes.*

---

## 🔗 Repositório Relacionado

- ⚙️ **API / Back-end (Java Spring Boot):** [Acesse o repositório da API aqui](https://github.com/jeangeneroso/controledepresenca)

---

## 🚀 Tecnologias Utilizadas

- **Angular**
- **TypeScript**
- **HTML5 / CSS3 / SCSS**
- **RxJS / HttpClient** (Consumo da API REST)

---

## 🖥️ Telas da Aplicação

| Tela | Descrição |
| :--- | :--- |
| **Login / Autenticação** | Acesso seguro dos colaboradores. |
| **Solicitação de Diárias** | Formulário para lançamento de diárias e justificativas. |
| **Painel de Controle** | Visualização de solicitações pendentes e aprovadas. |
